# Формат гайда

Гайд — JSON-объект (тип `Guide` в `src/shared/guide/types.ts`). Всё задаётся **игровыми ID**, поэтому формат не зависит от сайта и языка: Mobalytics, видео на YouTube, совет друга — всё переводится одинаково. Импорт проверяет и чинит файл (`normalizeGuide`): лишнее отбрасывается, веса ограничиваются 0…5.

## Поля

| Поле | Что это |
|---|---|
| `name`, `cls`, `mode` | Название, класс (`templar`, `gladiator`, …), назначение (`pve`, `pvp`, `leveling`, `other`) |
| `description`, `source` | Описание и источник (`title`, `url`, `author`, `date`) |
| `skills[]` | Цели по умениям: `skill` (ID), `role` (`core` главное, `support`, `passive`, `stigma`, `situational`), `level` — к какому итоговому уровню стремиться, `specs` — нужные специализации **по важности**, `earlySpecs` — что ставить, пока главные не открыты, `equip` — для стигм: держать надетой, `note` |
| `stats[]` | Веса статов `{ stat, weight }`: 5 — главное … 1 — «лучше, чем ничего»; не указан = 0 = бесполезно |
| `gear` | `skills[]` — какие умения хороши строкой на шмоте (с весом); по желанию свои веса статов для `weapon`, `armor`, `accessory`; `notes` |
| `manastones[]` | Веса статов для манакамней (иначе — общие) |
| `arcana` | `attack[]` и `passive[]` — умения по важности; `useless[]`; `preferredSet` (`magic` / `vigor`); `notes` |
| `daevanion.goals[]` | Цели: `name`, `description`, `skills[]` — у каких умений брать узлы «+1», `boards[]` — на каких досках (21–26 у стража), `nodes[]` — конкретные узлы |
| `genus.stats[]` | Веса статов для Познания рода (иначе — общие) |
| `rotation[]`, `tips[]`, `checklist[]` | Ротация по шагам, советы `{ title, text }`, разовые дела `{ id, text }` |

### Специализации

Номера вариантов 1–5 — как на страницах умений (в приложении: «Гайды → Изменить → Умения» показывает текст каждого варианта). Слоты открываются на ур. 8, 12, 20, варианты — на 8 / 12 / 16. Приложение само берёт из `specs` первые варианты, которые уже открыты и на которые хватает слотов; пока главных нет — добирает из `earlySpecs`.

## Как перевести новый гайд

**Руками:** «Гайды → Новый гайд» (или «Скопировать и править» встроенный) — всё выбирается из списков.

**Через AI-агента** (быстрее для длинной статьи): дайте агенту ссылку и попросите «сделай JSON гайда по docs/guides.md». Агенту:

1. ID умений — в `src/shared/gamedata/generated/skills.json` (поиск по английскому названию; у класса свой префикс: 12xxxxxx — страж).
2. Номера специализаций — в `generated/specs.json` (по ID умения) — сопоставить описания из гайда.
3. ID статов — в `generated/stats.json` (поле `en`). Если гайд не даёт веса — честно напишите в `note` первого стата, что это оценка.
4. Узлы досок: ID досок класса — в `generated/daevanion/<класс>.json`; проще всего задать цель через `skills` + `boards`.
5. Проверка: импортировать файл в приложении («Гайды → Импорт») — ошибки формата покажутся сразу.

## Минимальный пример

```json
{
  "name": "Страж PvE — мой вариант",
  "cls": "templar",
  "mode": "pve",
  "source": { "title": "Aion 2 Templar PvE Build", "url": "https://mobalytics.gg/gamebase/guides/aion-2-templar-pve-build" },
  "skills": [
    { "skill": 12240000, "role": "core", "level": 16, "specs": [5, 3], "earlySpecs": [3], "note": "Суд: снятие перезарядки + доп. урон" },
    { "skill": 12110000, "role": "stigma", "equip": true, "level": 5 }
  ],
  "stats": [
    { "stat": 317, "weight": 5 },
    { "stat": 128, "weight": 5 },
    { "stat": 282, "weight": 4 }
  ],
  "gear": { "skills": [{ "skill": 12780000, "weight": 5 }] },
  "arcana": { "attack": [12240000, 12010000, 12040000, 12090000], "passive": [12780000, 12730000], "useless": [12260000] },
  "daevanion": { "goals": [{ "id": "core", "name": "+1 к главным на 4 досках", "skills": [12240000, 12010000, 12040000, 12090000], "boards": [21, 22, 23, 24] }] },
  "genus": {}
}
```

Полный пример — встроенный гайд: «Гайды → Экспорт» сохранит его в файл.
