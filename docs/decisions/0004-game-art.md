# 0004 — Арт игры: список вручную, файлы локально

**Дата:** 2026-11-08 · **Статус:** принято

## Контекст

Хотелось, чтобы приложение выглядело как игра: иконки вещей, рамки грейдов, карты аркан, эмблемы титулов, пантеон. В файле оверлея есть только ID предметов. Публичные справочники (metabot.gg) не связывают ID вещи с её иконкой; закрытый API Questlog для сторонних программ не используем (запрос к нему был заблокирован — это обход доступа).

## Решение

- **Список арта — `src/shared/gamedata/art.json`, собранный вручную**: ID вещи → официальное русское название и путь к иконке на публичном CDN картинок Questlog (`cdn.questlog.gg/aion-2/...`). Пути и названия взяты с того, что показывает открытая страница билда персонажа (то же, что видит любой посетитель), и сверены с окнами игры.
- **Файлы лежат в приложении** (`src/renderer/public/art`, ~1,3 МБ) — интерфейс работает без интернета. Скачивает их `npm run art`; уже скачанные не трогает. Тест `art.test.ts` проверяет, что все файлы из списка на месте.
- **Где можно — правило, а не список**: карты аркан (тип и вариант из ID → `Icon_Arcana_Card_<Тип>_u_<Сет>`), рамки по грейду, камни маны по ID камня, эмблема титула по категории.
- **Вещи не из списка** рисуются заглушкой: рамка грейда (грейд берётся из ID) и значок слота. Название — по слоту; пользователь может дать своё.
- Титулы целиком (ID, грейд, категория, бонусы) собираются `npm run gamedata` с публичной таблицы metabot.gg; названия статов там официальные английские и переводятся в наши ID.

## Последствия

- Новая вещь появляется с иконкой, только когда её добавят в `art.json` (с той же страницы билда или из игры). Это ручная работа, но небольшая и прозрачная.
