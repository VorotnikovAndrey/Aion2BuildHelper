# 0006 — Свои значки статуса и три уровня анимаций

**Дата:** 2026-11-09 · **Статус:** принято

## Контекст

Значок статуса в углу вещей, умений и строк был кружком с иконкой lucide (галочка, треугольник, крестик) размером 15 px. Владелец сказал, что значки выглядят как очень плохое качество: треугольник внутри круга тесный и размытый, а все три значка одной формы — их различает только цвет. Ещё он попросил анимации, чтобы приложение выглядело «повеселее».

## Решение

- **Значки нарисованы в Figma** (файл «Aion2 Build Helper — значки статуса» в команде владельца, компонент `StatusBadge`, сетка 16 px) и перенесены как SVG в `components/StatusBadge.tsx`. У каждого статуса своя форма: круг с галочкой («как в гайде»), ромб с «!» («обратить внимание»), восьмиугольник с крестиком («не по гайду»), скруглённый квадрат с «i» («к сведению»). Значок объёмный: градиент из токена (+35% белого сверху, ×0,78 снизу), обводка внутрь (×0,28), блик, тень. Ромб на 2 px крупнее: иначе он кажется мельче остальных. Цвета берутся из токенов темы, в коде нет hex-цветов.
- **Анимации — три уровня** в «Оформлении» (`UiPrefs.motion`): «Полные» (по умолчанию), «Спокойные», «Выключены». Уровень пишется в `data-motion` на `<html>`; по нему `styles.css` убирает декоративные эффекты, а компоненты читают его через `lib/motion.ts` (`useAnimate`, `useFancy`). Режим `?static` и системное «уменьшить движение» сильнее выбора в приложении: `?static` выключает всё, «уменьшить движение» понижает «Полные» до «Спокойных».
- Что анимируется: появление карточек, полосы и кольца, баллы набегают (`CountUp`), подсветка пункта меню переезжает (`layoutId`), значки статуса выпрыгивают, по иконкам редких вещей пробегает блеск, на фоне медленный эфир (пятна света и искры), при отметке пункта чек-листа разлетаются искры, когда приходят свежие данные — точка внизу меню «пингует», кнопки чуть проседают при нажатии.

## Последствия

- Новые значки статуса — только через `StatusBadge` (форма, цвет и знак вместе). Lucide-иконки остаются для интерфейса (меню, кнопки), но не для статусов.
- Новые анимации проверяются на всех трёх уровнях. Декоративное (то, что движется само) — только при «Полных», через класс `fx-ambient` / `fx-shine` или `useFancy()`.
- Автоскриншоты (`npm run shots`) снимаются с `?static` — на них всё в конечном состоянии.
