# 0005 — Цель — сводный гайд, а не один чужой

**Дата:** 2026-11-08 · **Статус:** принято

## Контекст

Приложение сравнивало персонажа с одним гайдом (Mobalytics). Гайды расходятся: в стигмах, во втором варианте специализаций, в целевых уровнях. Часть гайдов написана по корейской версии, где 6 слотов стигм и другие патчи. Следовать одному вслепую — значит наследовать его частные решения и устаревания.

## Решение

- Цель по умолчанию — **встроенный сводный гайд** `templarPveConsensus`: 8 гайдов для глобальной версии + статистика 3 741 топ-стража глобальных серверов (metabot.gg). Разбор, таблицы согласия и что откуда — `docs/research/templar-pve-2026-11.md`.
- Правило сведения: **сначала данные игроков** (что реально носят: уровни, стигмы, узлы досок, арканы, шмот, титулы), **затем большинство гайдов**; где данных нет (специализации) — большинство гайдов с учётом патчей глобальной версии. Корейские советы проверяются на совместимость (4 слота стигм, патч 4.09, доска Ариэль).
- В заметке к каждому решению — степень согласия («5 из 7», «топ: 81%»), чтобы игрок видел, где совет твёрдый, а где спорный.
- Формат гайда расширен необязательными полями: `sources[]` (источник, дата, версия игры, статья или данные) и `titles` (рекомендуемые титулы по категориям). Старые гайды импортируются как раньше.
- Mobalytics остаётся вторым встроенным гайдом — переключение в «Гайдах».

## Последствия

- Сводный гайд надо пересобирать после крупных патчей: перечитать источники, обновить статистику топ-игроков, поправить файл гайда и разбор.
- Совет «гайд советует надеть титул» берётся из списка гайда; если списка нет — оценка помощника по важности статов.
