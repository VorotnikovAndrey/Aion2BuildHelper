# 0002 — JSON-файлы вместо базы данных

**Дата:** 2026-11-08 · **Статус:** принято

## Контекст

Данных мало: настройки, десяток гайдов, история до нескольких тысяч записей на персонажа.

## Решение

Обычные JSON-файлы в `%APPDATA%\Aion2 Build Helper` (`settings.json`, `guides/`, `history/`, `snapshots/`). Запись через временный файл и `rename` — при сбое старый файл остаётся целым. История ограничена 3000 записями на персонажа.

## Последствия

Файлы можно открыть, скопировать, отредактировать руками; нет нативных зависимостей. Если история разрастётся — перейти на SQLite, формат записи (`HistoryEntry`) сохранить.
