# 0008 — Встроенные гайды из билдов Questlog, со стадиями прокачки

**Дата:** 2026-11-09 · **Статус:** принято · заменяет [0005](0005-consensus-guide.md)

## Контекст

До 0.16 встроенные гайды были «сводными»: помощник читал 7–9 статей с разных сайтов (Mobalytics, MetaRoad, ExpCarry…) и сводил их вручную, плюс статистика топ-игроков metabot.gg. Владелец решил опираться на одно сообщество, где билды структурированы, — Questlog, — и брать по 5 самых популярных билдов на класс. Ещё ему нужна раскладка по стадиям прокачки («1600 GS», «1800 GS», «Final Setup»), которая есть в билдах Questlog, — чтобы выбрать целевую стадию.

## Решение

- **Источник — «Билды персонажей» Questlog**, 5 самых популярных (по лайкам) на класс, PvP-билды и PvP-стадии пропускаем. У каждого билда — стадии; у стадии — ссылки на билд умений и раскладку досок автора. Каждый билд Questlog — отдельный встроенный гайд; по умолчанию у класса — самый популярный.
- **Сбор**: страницы билдов открываются во встроенном браузере, и берутся данные, которые страница уже загрузила для показа (стадии, вещи с ID, умения, связки, узлы досок; характеристики — с отрисованной панели). Своих запросов к API Questlog не делаем. Данные — в `.cache/questlog-builds/`, гайды из них — `npm run guides` (`scripts/guides/questlog-guides.mjs`) → `src/shared/guide/builtin/questlog/<класс>.json`.
- **Стадии в формате гайда** (`Guide.stages`, `GuideStage`): уровни и специализации умений, стигмы, связка, доски, титулы, арканы, ориентиры по статам (меткость, крит, скорость боя у автора на этой стадии) и снаряжение по слотам. Стадия заменяет те же поля гайда (`applyStage`).
- **Целевая стадия** выбирается у персонажа (`CharacterPrefs.stages`); по умолчанию — ближайшая впереди по уровню снаряжения (`pickStage`). Переключатель — рядом с выбором гайда в шапке страниц.
- **Чего в билдах нет — оценка помощника, с пометкой**: веса статов шмота и камней (по частоте выбора: 60% — автор, 40% — пять авторов класса), приоритеты Знания о видах, «одна кнопка» (макрос мыши владельца).
- Старые сводные гайды удалены; сводный гайд стража и гайд Mobalytics оставлены как тестовые данные (`src/shared/testing/`) — на них построены тесты разбора.

## Последствия

- Гайды точнее отражают реальные билды (ID вещей, узлов, умений вместо пересказа статей), есть стадии, но меньше «объяснений»: советов и заметок авторов почти нет, описание автора — как есть (обычно на английском).
- Веса статов — производная от выбора авторов, а не прямое мнение; оценки шмота поменялись (у владельца ниже, чем со сводным гайдом).
- План досок по полной раскладке автора (до 380 узлов) потребовал быстрого поиска путей: расстояния до всех узлов доски считаются одним проходом (`routesFrom`).
- Обновление: собрать билды заново (docs/data-sources.md) и `npm run guides`.
