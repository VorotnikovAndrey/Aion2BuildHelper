# 0012 — PvP-гайды из интернета (не Questlog)

**Дата:** 2026-11-10 · **Статус:** принято (исключение из decisions/0008)

## Контекст

С 0.16 встроенные гайды берутся только с Questlog. В 0.19 добавились PvP-билды Questlog, но их мало и они слабые (у чародея — один, у многих классов — с 1 лайком). Владелец попросил: «найди в интернете по три топ PvP-гайда, проанализируй их и засунь в приложение — с пометкой, что источник не из Questlog».

## Решение

- **Исключение только для PvP.** До 3 PvP-гайдов на класс из статей на сайтах (не questlog.gg): по одному гайду на статью, лучший — первым. PvE-гайды по-прежнему только с Questlog.
- **Перевод статьи в формат приложения — помощником** (по агенту на класс): умения и специализации, стигмы, веса статов по порядку приоритетов из статьи (это оценка, подписано), камни, арканы, титулы, доски, связка и ротация — то, что в статье есть; чего нет — не придумываем. Всё по игровым ID, проверяется тем же тестом, что и билды Questlog (`builtin/allClasses.test.ts`).
- **Тексты статьи не копируем**: описание и советы — короткий пересказ помощника по-английски (как тексты авторов Questlog), свои пометки — ключами перевода (`$t`).
- **Хранение:** `src/shared/guide/builtin/web/<класс>.json` — правится руками/агентом (скрипта сборки нет, статьи разные). `source.kind: 'guide'`, ссылка на статью; загрузка — после билдов Questlog класса, поэтому гайд по умолчанию — PvE-билд Questlog.
- **Пометка в интерфейсе:** на странице «Гайды» — своя группа «PvP из интернета · не Questlog», у гайда — сайт и жёлтая пометка «не Questlog» (обратить внимание: сверяйтесь с оригиналом), в карточке — «Открыть статью на <сайт>», в выборе гайда — «не Questlog · <сайт>».

## Последствия

- Такие гайды устаревают вместе со статьями; обновлять — тем же способом (агент по статье → JSON → тест). Список статей — `docs/research/pvp-web-guides-2026-11.md`.
- Специализации и уровни умений в статьях часто описаны словами — сопоставление с номерами вариантов может ошибаться; в интерфейсе гайд помечен, а в отчёте агентов спорные места перечислены (см. research).
