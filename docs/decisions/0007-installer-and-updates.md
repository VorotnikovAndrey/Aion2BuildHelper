# 0007 — Установщик и автообновление через выпуски GitHub

**Дата:** 2026-11-09 · **Статус:** принято

## Контекст

Приложение запускалось только из исходников: Node.js, `npm install`, ярлык, который каждый раз пересобирает код. Владелец захотел дать программу другу (он играет за клерика) и «легко подкидывать обновления», как в соседнем проекте IndieRocket.

## Решение

- **Установщик NSIS** (electron-builder, `electron-builder.yml`): для текущего пользователя, без прав администратора, ярлыки на рабочем столе и в «Пуске». Настройки, свои гайды и история (`%APPDATA%\Aion2 Build Helper`) при удалении и обновлении не трогаются.
- **Обновления — electron-updater** (`src/main/updater.ts`, состояние и помощники — `src/shared/updates.ts`, взяты из IndieRocket). Установленное приложение проверяет выпуски через 15 секунд после запуска и раз в 4 часа, скачивает новую версию в фоне и ставит её при перезапуске; кнопка «Перезапустить и обновить» — в «Настройках» и внизу меню. Автоскачивание можно выключить.
- **Выпуски — в самом репозитории `VorotnikovAndrey/Aion2BuildHelper`**, а не в отдельном закрытом, как в IndieRocket: код и так открыт, поэтому установщику не нужен вшитый ключ «только чтение». Ключ «запись» нужен только для выкладки (`npm run release`) и хранится вне проекта: `%USERPROFILE%\.aion2buildhelper-release\release-token.txt`.
- **`npm run release`** (`scripts/release.mjs`): проверяет, что всё закоммичено и отправлено, берёт раздел версии из `CHANGELOG.md` как «Что нового», собирает установщик, выкладывает выпуск черновиком, грузит установщик, `.blockmap` и `latest.yml` (последним) и только потом публикует. Проверяет, что в сборку попал `electron-updater`.

## Последствия

- Установщик и выпуски видны всем, кто откроет страницу выпусков (как и код). Личных данных в сборке нет: всё личное лежит в `%APPDATA%` на компьютере игрока.
- Установщик не подписан: Windows SmartScreen при первом запуске предупреждает («Подробнее» → «Выполнить в любом случае»). Подпись стоит денег — для программы «для друзей» не нужна.
- Новая версия = поднять `version` в `package.json`, добавить раздел в `CHANGELOG.md`, закоммитить, отправить, `npm run release`. Запуск из исходников (`npm run dev`, ярлык разработчика) обновления не проверяет — состояние «Запущено не из установщика».
