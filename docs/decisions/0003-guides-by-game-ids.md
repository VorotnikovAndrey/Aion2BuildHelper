# 0003 — Гайды описываются игровыми ID

**Дата:** 2026-11-08 · **Статус:** принято

## Контекст

Гайды будут разные и из разных мест (Mobalytics, видео, свои), на английском и русском, и меняются по мере прогресса. Нужен один универсальный формат.

## Решение

Гайд — JSON (`shared/guide/types.ts`), где умения, специализации, статы и узлы досок заданы **ID игры**, а важность — весами 0–5 и порядком. Названия появляются только в интерфейсе через `Namer`. Встроенные гайды — код (`guide/builtin`), свои — файлы; импорт проходит через `normalizeGuide`. Каждый персонаж следует своему гайду, переключение — в один клик.

Если гайд чего-то не говорит (например, приоритет статов), а без этого не построить подсказки, — помощник ставит свою оценку и помечает её в `note`.

## Последствия

- Любой гайд переносится одинаково; смена языка названий не ломает гайды.
- Перевод статьи в JSON требует сопоставить названия с ID — делается в редакторе или AI-агентом по docs/guides.md.
