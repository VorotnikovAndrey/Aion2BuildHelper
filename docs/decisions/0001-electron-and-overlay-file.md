# 0001 — Electron и данные из файла оверлея

**Дата:** 2026-11-08 · **Статус:** принято

## Контекст

Нужно видеть актуального персонажа без ручного ввода. Игра не даёт публичного API для глобальной версии; оверлей Questlog уже снимает персонажа и сохраняет его локально в `%APPDATA%\Questlog\aion-2\characters.json`. Названий в файле нет — оверлей берёт их со своего закрытого API.

## Решение

- **Десктоп на Electron** (как соседний проект IndieRocket): нужен доступ к локальному файлу и слежение за ним; тот же стек — те же наработки и планка качества.
- **Источник — только локальный файл оверлея.** Читаем и следим (`fs.watch` + опрос). В игру не лезем, сетевых запросов приложение не делает.
- **Закрытый API Questlog не используем** — это внутренний API их приложения.
- **Названия и игровые справочники** собираем один раз скриптом с публичных страниц metabot.gg (база из клиента) и храним в репозитории.
- Для разработки — тот же интерфейс в браузере (`npm run dev:web`) с реализацией `window.api` поверх dev-сервера.

## Последствия

- Без Questlog приложение пустое — экран «Нет данных» объясняет, что сделать.
- Формат файла может поменяться — разбор терпимый, а тесты фиксируют известный формат.
- Названий предметов нет — вещи называются по слоту, пользователь может переименовать.
