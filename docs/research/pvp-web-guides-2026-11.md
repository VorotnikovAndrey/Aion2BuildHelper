# PvP-гайды из интернета — не Questlog (10 ноября 2026)

Встроенные PvP-гайды из статей на сайтах — исключение из «только Questlog» по просьбе владельца ([decisions/0012](../decisions/0012-pvp-web-guides.md)). По три на класс, лучший — первым; каждый собран помощником по тексту статьи в `src/shared/guide/builtin/web/<класс>.json`. Тексты статей не копировались: описание и советы — короткий пересказ. Не брали: questlog.gg и сайты, собранные из билдов Questlog (aion2vault, gamerstogether.cz). Mobalytics не отдаёт страницы (403), у Maxroll PvP-страниц AION 2 не нашлось.

Общее для всех: специализации внутри умения статьи обычно не ранжируют — порядок оценка помощника; веса статов — по порядку приоритетов статьи (числами их никто не даёт).
