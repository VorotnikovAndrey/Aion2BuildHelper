# Билды Questlog — встроенные гайды (9 ноября 2026)

Встроенные гайды приложения — 5 самых популярных (по лайкам) «Билдов персонажей» каждого класса на [questlog.gg](https://questlog.gg/aion-2/ru/character-builder) (решение — [decisions/0008](../decisions/0008-questlog-guides-with-stages.md)). PvP-билды и PvP-стадии пропущены. Данные — `src/shared/guide/builtin/questlog/<класс>.json`, собираются `npm run guides` из `.cache/questlog-builds/` (как собрать — [data-sources.md](../data-sources.md)).

Что берётся из билда: стадии (их название, уровень снаряжения по расчёту Questlog, теги), для каждой стадии — связанный билд умений (уровни, специализации, стигмы, приоритет, связки с задержками), раскладка досок Даэваниона, титулы, арканы, характеристики (меткость, крит, скорость боя — ориентиры) и снаряжение по слотам (вещь, заточка, строки, камни).

Что **не** из билда (оценка помощника, подписано в интерфейсе): веса статов шмота и камней — по тому, как часто их берут (60% — автор, 40% — пять авторов класса); приоритеты Знания о видах; «одна кнопка» — макрос мыши владельца.
