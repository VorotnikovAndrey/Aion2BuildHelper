# Источники данных

## 1. Персонаж — файл оверлея Questlog

`%APPDATA%\Questlog\aion-2\characters.json`. Оверлей Questlog (desktop-приложение questlog.gg для AION 2) пишет его сам, пока запущена игра; обновление — обычно при смене зоны. Приложение только **читает** файл.

Рядом лежат и другие файлы оверлея (`currencies.json`, `tickets.json`, `checklist.json`, `game-data-v2.json` …) — сейчас используется только `game-data-v2.json` (статы, при сборке справочников).

### Формат (что знаем, ноябрь 2026)

```jsonc
{
  "characters": {
    "1001:Hero": {                    // ключ «сервер:имя»
      "name": "Hero", "server": 1001, "class": "templar", "level": 45,
      "gearScore": 2600, "combatPower": 130000, "legion": "LEGION", "race": "light",
      "updatedAt": 1794161591961,     // когда оверлей видел персонажа (мс)
      "gear": [{
        "item": 110230096, "slot": 1, "enchant": 14, "surpass": 0, "itemLevel": 91,
        "stats": [{ "stat": 28, "value": 594 }],      // строки вещи; % — в сотых долях (594 = 5,94%)
        "soulStats": [],
        "skills": [{ "skill": 12760000, "level": 1 }], // у аркан одно умение повторяется — уровни складываются
        "manastones": [{ "stone": 531360001, "stat": 199, "grade": 1 }],
        "godstones": [19950010]
      }],
      "daevanion": [{ "board": 21, "nodes": [210113, 210033] }],  // взятые узлы
      "pets": [{ "pet": 1002, "level": 3 }],                     // уровень 1–3
      "titles": [12030002], "ownedTitles": [...], "skins": [...],
      "monoliths": [{ "monolith": 1001, "tokens": 560 }],
      "pantheon": [{ "slot": 5, "deco": 57 }],                    // украшения зала легиона
      "wings": [{ "wing": 30101000, "level": 0 }], "equippedWing": 30101000,
      "genus": [{ "genus": "intellect", "level": 7,
                  "effects": [{ "slot": 0, "grade": 3, "option": 587, "value": 10 }] }],
      "skills": [{ "skill": 12010000, "level": 17, "equipped": true, "specializations": [1, 2] }],
      "abyssSeason": { "grade": 18, "points": 100000, "kills": 5, "deaths": 30, "assists": 20 },
      "stats": [{ "stat": 2, "value": 53 }]                       // итоговый лист характеристик
    }
  },
  "roster": { "1001:Alt": { "name": "...", "class": "sorcerer", "level": 16, ... } } // все персонажи аккаунта
}
```

**Слоты** (`gamedata/slots.ts`): 1 оружие, 2 гарда, 3 шлем, 4 наплечники, 5 нагрудник, 6 поножи, 7 перчатки, 8 сапоги, 9 подвеска, 10 ожерелье, 11–12 серьги, 13–14 кольца, 15–16 браслеты, 17 пояс, 18/20 броши, 19 плащ, 22 амулет, 23–24 руны, 25–26 печати; **41–45 арканы** (Грааль, Пергамент, Компас, Колокол, Зеркало), 46–50 — ещё не открытые типы карт.

**`skills[].level`** — итоговый уровень (с досками, арканами и шмотом). База считается вычитанием.

**`skills[].specializations`** — ⚠️ у всех активных умений `[1, 2]`, у стигм `[1, 2, 3, 4]`. Похоже, это открытые слоты, а не выбранные варианты; приложение это распознаёт (`specsLookLikeSlots`) и просит отметить вручную.

**Кроме скилов класса** в `skills` есть служебные ID (301, 1001…, 12010450 — цепные удары и т.п.) — приложение их не показывает.

**Названий нет** — только ID. Оверлей берёт названия со своего закрытого API questlog.gg; мы его **не используем**.

### Когда оверлей обновляет доски Даэваниона

Оверлей переписывает `characters.json` при смене зоны и других событиях, но **доски Даэваниона — не сразу**: 9 ноября 2026 после перестановки узлов файл получил новые уровни умений и статы, а список узлов остался прежним. Приложение ловит это по несоответствию: уровень умения больше, чем 10 (максимум очками) + бонусы досок, аркан и шмота из файла (`unexplainedLevels` в `analysis/skills.ts`), — и предупреждает, что доски пока прежние. **Перезаход персонажем не помогает**: в 00:28 того же дня файл переписан после входа в мир, а узлы прежние. Новые доски пришли в файл позже сами: история приложения записала «Даэванион: +4 / −4 узла» по данным оверлея около 12:00 того же дня, то есть примерно через 12 часов после перестановки, без каких-либо действий в приложении. Что именно их подтянуло (ежедневный сброс, следующий сеанс игры или задержка на стороне Questlog) — неизвестно. Обратный случай (сняли узел с умением) по уровням не виден.

**Знание о видах — похоже, так же.** 9 ноября друг перекрутил статы в ячейках рода, а приложение их не увидело. Отдельных отметок времени у разделов файла нет (только общий `updatedAt` персонажа), поэтому по файлу не понять, когда оверлей прислал род в последний раз. У владельца изменения рода пришли в одном обновлении с досками (история, 9 ноября около 12:00). Что заставляет оверлей перечитать род (окно рода, смена зоны, следующий сеанс), не проверено. С 0.14.1 страницы «Знание о видах» и «Даэванион» показывают, когда оверлей видел персонажа и когда раздел менялся в истории (`analysis/freshness.ts`), и объясняют игроку, что делать.

## 2. Справочники — `npm run gamedata`

Скрипт `scripts/gamedata/build-gamedata.mjs` собирает `src/shared/gamedata/generated/`:

| Файл | Откуда | Что |
|---|---|---|
| `stats.json` | локальный `game-data-v2.json` оверлея | 540 статов: ID, ключ, официальное английское название, категория, процентный ли |
| `skills.json` | metabot.gg/en/aion-2/skills | 279 умений всех 8 классов: ID, название, класс, тип, уровень открытия, порядок |
| `specs.json` | страницы умений metabot.gg | специализации (вариант, уровень, описание на английском) — собраны все 8 классов |
| `daevanion/<класс>.json` | metabot.gg/en/aion-2/daevanion/<класс> | 6 досок: узлы с координатами, типом, грейдом, стоимостью, статами или умением |
| `arcana-pools.json` | metabot.gg/en/aion-2/arcana | какие умения класса могут выпасть на каждом типе карты |

MetaBot собирает свою базу из клиента глобальной версии (английские названия — официальные). Скрипт кэширует страницы в `.cache/gamedata` и делает паузы между запросами; повторный запуск без `--refresh` не ходит в сеть.

```bash
npm run gamedata                               # страж
npm run gamedata -- --classes templar,chanter  # несколько классов
npm run gamedata -- --classes all --refresh    # всё заново
```

После обновления: `npm test` (тест проверяет, что встроенные гайды ссылаются на существующие ID).

### Названия умений и вещей (база Questlog на русском)

- `gamedata/skills-ru.json` — русские названия умений всех 8 классов, как в клиенте: страницы `questlog.gg/aion-2/ru/db/skills/<класс>` (у заклинателя — `elementalist`). Поправки поверх — `RU_OVERRIDES` в `skills.ts`.
- `gamedata/specs-ru.json` — русские тексты специализаций 7 классов (кроме стража — у него свои, сверенные по видео, в `SPEC_RU`): блок «Specialty» страниц `questlog.gg/aion-2/ru/db/skill/<ID>`, 784 строки, уровни открытия сверены со `specs.json`. Пятого варианта стигм (без уровня) в базе нет — эти 91 строку перевёл помощник с английского (`stigma5`); в редакторе гайда у них подсказка «перевод помощника».
- `gamedata/items.json` — снаряжение всех классов (оружие, броня, украшения; 3 515 вещей): ID → официальное русское название и путь к иконке. Страницы `questlog.gg/aion-2/ru/db/items/<группа>/<тип>`. Иконки этих вещей в приложение не кладутся (их больше тысячи): интерфейс грузит их с публичного сервера картинок Questlog (`cdn.questlog.gg`, разрешён в CSP `index.html`), без интернета — значок слота. Свой арт (`art.json`, лежит в приложении) важнее.
- Как собирали (9 ноября 2026): страницы базы открывались во встроенном браузере, со страницы читался уже показанный текст и ссылки (закрытый API Questlog не используется). Обновить — тем же способом; помощник может сделать это по просьбе.

### Топ-игроки и дата сборки

`generated/top/<класс>.json` — что носят топ-игроки класса (публичная страница metabot.gg/en/aion-2/classes/<класс>/build, раздел «What top … players run»): сколько игроков и их боевая мощь по диапазонам, доля и средний уровень каждого умения и стигмы, узлы досок «у большинства», заточка по слотам, вещи, камни, арканы, титулы, крылья. Страница разбирается по тексту (`scripts/gamedata/top-players.mjs`); английские названия умений и статов сопоставляются с нашими ID. `generated/meta.json` — дата сборки справочников.

### Проверка после патча

Разбор страниц вынесен в `scripts/gamedata/parsers.mjs` — им пользуются и `npm run gamedata`, и приложение («Настройки» → «Справочники игры» → «Проверить обновления», `src/main/gamedataCheck.ts`). Приложение скачивает свежие страницы с паузами между запросами (≈30 страниц, около 30 секунд), сравнивает со своими справочниками (`shared/gamedata/diff.ts`) и показывает изменения. Само оно справочники не перезаписывает: они встроены в сборку, обновляются `npm run gamedata -- --refresh`.

### Иконки

Скрипт также скачивает иконки умений (`src/renderer/public/icons/skills/<ID>.webp`, 256×256 — арт клиента) и значки специализаций (`icons/specs/spec-1…5.webp` — пять цветных щитов активных умений, `spec-stigma.webp` — золотой значок стигм; у всех умений они одинаковые, поэтому хранится шесть файлов).

### Как получить титулы

`TITLE_HOW` в `gamedata/titles.ts` — условия получения титулов из списков встроенных гайдов (страницы титулов на metabot.gg, 9 ноября 2026): достижение, условие по-русски и что считать для прогресса (`track`: самый низкий род, питомцы, крылья, облики, лучшая заточка уникальной вещи). Для прочих титулов показывается короткая строка `source` из справочника.

### Священные камни

`generated/godstones.json` — все священные камни (Theostone) с публичной таблицы metabot.gg: ID, английское название, грейд, эффект; иконки — `public/icons/godstones/<ID>.webp`. Гнездо — одно в оружии и в наручах (`gamedata/godstones.ts`). Эффект переводится по шаблонам (`godstoneEffectRu`); тест следит, что переводятся все.

### Титулы

`generated/titles.json` — все титулы с публичной таблицы metabot.gg: ID, грейд, категория (атака / защита / другое), бонус при ношении и «эффект при наличии». Названия статов там — официальные английские из клиента, скрипт переводит их в наши ID статов (совпадают все). Русские названия титулов — `gamedata/titles.ts` (`TITLE_RU`, из окна «Титулы» и страницы билда), остальные пока по-английски.

## 2б. Встроенные гайды — билды Questlog, `npm run guides`

С 0.16 встроенные гайды — 5 самых популярных (по лайкам) «Билдов персонажей» каждого класса на questlog.gg, с 0.19 — ещё до 5 PvP-билдов (decisions/0011) ([decisions/0008](decisions/0008-questlog-guides-with-stages.md), список — [research/questlog-builds-2026-11.md](research/questlog-builds-2026-11.md)).

**Сбор** (вручную, во встроенном браузере, как базы умений и вещей): страница класса `questlog.gg/aion-2/ru/character-builder?class=<класс>` (у заклинателя — `elementalist`) даёт список билдов с лайками; страница билда уже загружает все его стадии, связанные билды умений и раскладки досок — их и берём (данные, загруженные страницей для показа, без своих запросов к API Questlog). Характеристики стадии (уровень снаряжения, меткость, крит…) — с отрисованной панели «Характеристики» после переключения стадии. Всё складывается в `.cache/questlog-builds/<класс>.json` (не в git). PvP — то же со страницы класса с фильтром «PvP» (`character-builder?class=<класс>&tag=pvp`): до 5 билдов по лайкам без «(Clone)» и без билдов с 0 лайков → `.cache/questlog-builds-pvp/<класс>.json`. Прямые запросы со страницы Questlog на локальный адрес браузер блокирует, поэтому данные передаются переходом на локальный приёмник с данными во фрагменте адреса (base64), а его страница отправляет их себе же.

**Сборка**: `npm run guides` (`scripts/guides/questlog-guides.mjs`) → `src/shared/guide/builtin/questlog/<класс>.json` (руками не править). Что делает скрипт:
- у PvE-гайда — стадии без PvP (`pvp` без `pve` в тегах, «[PvP]» в названии), у PvP-гайда (`id` с `-pvp`, `mode: 'pvp'`) — только PvP-стадии (тег `pvp` или «PvP» в названии; не помечены — все), ориентир меткости — «в PvP»; у стадии — умения из связанного билда умений (уровни, специализации `ID умения + n×10`, стигмы на панели — надеты), связки (каждый шаг — одно умение, задержка — наименьшая), узлы доски, титулы (номер другой расы — к нашему: 23010021 → 13010021), арканы (набор — по последней цифре ID карт), ориентиры по характеристикам и снаряжение по слотам;
- только умения своего класса и известные узлы (встречаются ошибки авторов);
- веса статов шмота, камней и умений на шмоте — по частоте выбора (60% — автор, 40% — пять авторов класса того же режима), приоритеты Знания о видах — оценка помощника (для PvP — своя);
- советы автора (`tips`): описание билда, заметки стадий, описания связанных билдов умений и раскладок досок — HTML в текст, одинаковые один раз со списком стадий;
- свои тексты (описание, заметки, названия целей) — ключами перевода (`$t`), см. decisions/0010.

### Что дают статы богов и характеристики

`src/shared/gamedata/deities.ts` — описания из клиента (поле `description` статов категорий `Conqueror` и `MainStat` в локальном `game-data-v2.json` оверлея, английский клиент), переведены на русский словами русского клиента («Совершенный удар», «Мощный удар», «Регенерация», «Непробиваемость» — как на странице билда Questlog на русском). У Ариэля и Асфеля описания в клиенте нет. Сколько даёт одно очко, в данных нет — не показываем.

### Эмблемы богов и значки характеристик

`src/renderer/public/icons/deities/<стат>.png` (10 эмблем) и `icons/attributes/<характеристика>.png` (6 характеристик: might, agility, precision, will, intellect, health — не `con.png`: CON — зарезервированное имя в Windows) — вырезаны из скриншота окна «Показатели персонажа» (присланного владельцем, 9 ноября 2026): фон убран, цифры значения стёрты (на их месте приложение пишет своё число), цвет задаёт тема через маску. Готовых файлов этих значков нет ни на cdn.questlog.gg, ни на metabot.gg. Какой из двух значков с «11» — Маркутан (звезда, «3 часа»), а какой — Румиэль (весы, «4 часа»), по скриншоту не проверить: расставлено по парам богов (Кайсинель ↔ Маркутан, Юстиэль ↔ Румиэль).

## 2а. Арт игры — `npm run art`

Список — `src/shared/gamedata/art.json` (собран вручную, см. decisions/0004): ID вещи → официальное русское название и путь к иконке на публичном CDN картинок Questlog; рамки грейдов, камни, карты аркан, эмблемы титулов, украшения пантеона, эмблемы классов. `npm run art` скачивает файлы в `src/renderer/public/art/<группа>/` (уже скачанные пропускает). Тест `gamedata/art.test.ts` проверяет, что все файлы на месте.

Чтобы добавить новую вещь: открыть страницу билда персонажа на questlog.gg, найти вещь в сетке снаряжения, взять путь картинки (`assets/Game/UI/Resource/Texture/Item/...webp`) и название из окна вещи, дописать в `items` и запустить `npm run art`. Сопоставление с ID — по слоту и заточке из файла оверлея.

Исправления иконок умений — `skillIcons` (ID умения → картинка игры): там, где metabot отдаёт неверный арт (общие со гладиатором пассивки «Попадание шоком» и «Инстинкт выживания»). Интерфейс берёт путь к иконке умения только через `skillIconSrc` (`gamedata/art.ts`).

Что известно о кодах:
- **Камни**: `5313600Q` — камень маны (оружие, броня), `5335600Q` — духовный камень (украшения); Q: 1–2 простой, 3 средний, 4 качественный.
- **Грейд вещи** — пятая цифра ID: 1 мифический, 2 эпический, 3 уникальный, 4 легендарный, 5 редкий, 6 обычный. Руны (`3109…`) — «особые», грейд задан в списке.
- **Карты аркан**: «магия» (вариант 2) — арт `DefenceSet2`, «жизнь» (вариант 1) — `PveSet2`; есть только у уникальных.
- **Пантеон**: слоты 1–12 — картины (1–6 справа сверху вниз, 7–12 слева снизу вверх), 13–16 — статуи, 17 — колосс; `deco` — ID украшения.

## 3. Знания, собранные вручную

- **Русские названия** — `gamedata/stats.ts` (`RU`) и `gamedata/skills.ts` (`RU_BY_ID`, `SPEC_RU`). Названия умений стража сверены с базой умений Questlog на русском (`questlog.gg/aion-2/ru/db/skills/templar` — тексты из клиента, 9 ноября 2026), формулировки специализаций — с видео окна умений (8 ноября 2026). В клиенте два разных умения называются «Удар щитом» (12100000 и 12430000) — у второго приложение пишет «Удар щитом (рывок)». До 0.10.0 четыре названия были нашим переводом и три оказались неверными: «Рывок со щитом», «Щит защиты» (в игре — «Щит спасения»), «Охранная печать» («Печать защиты»), «Боевой товарищ» («Плечом к плечу»). Названия статов сверены с окнами «Показатели персонажа», «Пантеон», «Арканы» и страницей билда Questlog на русском; редкие статы — наш перевод. Пользователь может переименовать умения в настройках.
- **Опции шмота по слотам** — `gamedata/gearOptions.ts`, собраны по наблюдениям и дополняются данными персонажей. **Ячейки рода** — `gamedata/genus-ranges.json`: таблица свойств ячеек с публичных страниц `wikily.gg/aion-2/genus-insight/<род>/slot-properties` (2 062 строки: стат, грейд, пределы, шанс; 9 ноября 2026), шансы грейдов по уровню рода — оттуда же. Сверена с данными оверлея (111 ячеек — все в пределах). Статы «против рода» («АТК против диких»…) — наш перевод, в клиенте не сверен.
- **Расшифровка ID аркан** — `81 TT G 000V` (тип, грейд, вариант) — `gamedata/arcana.ts`.
