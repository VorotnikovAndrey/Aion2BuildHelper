## Что важно помнить (быстрый контекст)

- Владелец — игрок AION 2 (глобальная версия, Steam), основной персонаж — **страж**, PvE. Встроенные гайды — **билды Questlog** (decisions/0008): 5 самых популярных на класс, со стадиями прокачки; по умолчанию — самый популярный и ближайшая стадия впереди. С 0.19 — ещё до 5 PvP-билдов на класс (фильтр Questlog «PvP», decisions/0011) и советы авторов (страница «Советы автора», комментарий в «Ротации»). Других источников для гайдов не используем.
- Данные персонажа — **только из локального файла оверлея Questlog**. Закрытый API Questlog не используем (это их внутренний API, не для сторонних программ).
- Справочники собраны скриптом `npm run gamedata` с публичных страниц metabot.gg (умения, специализации, доски, пулы аркан) и из локального `game-data-v2.json` Questlog (статы). Собраны все 8 классов глобальной версии; девятого, «Мастера кулака» (есть только в Корее), пока нет.
- Названий и иконок предметов в данных оверлея нет. Известные вещи (надетые у владельца) — в `gamedata/art.json` с официальными названиями и артом (decisions/0004); остальные называются по слоту, пользователь может дать своё имя. Арканы называются точно (их ID расшифровываются).

## Что под вопросом

- **PvP-гайды**: PvP-билдов на Questlog мало (у чародея — один, у заклинателя — три, у многих классов есть билды с 1 лайком), поэтому они слабее PvE. Приоритеты Знания о видах для PvP — оценка помощника; отдельных PvP-порогов (меткость, крит) для контента нет — только «как у автора на стадии».

- **Переводы интерфейса** (украинский, английский, немецкий, французский, испанский, португальский, японский, корейский) сделаны помощником и носителями не вычитаны. Игровые названия на этих языках — английские официальные (русские — по выбору): официальных немецких, японских и других названий в справочниках пока нет (decisions/0010).

- **Названия.** Русский клиент сверен по видео окна умений, окнам игры и странице билда Questlog на русском; четыре названия умений стража и редкие статы пока — перевод приложения (см. data-sources.md). Не сверено: русские названия грейдов, вариант аркан «жизни» («Зеркало жизни»), пятый род «Особый».
- **Грейды ячеек Знания о видах**: порядок цветов (оранжевый выше золотого) выведен из совета SolAshur «запирать золото сейчас, оранжевое — позже»; названия грейдов — наши.
- **Пантеон**: какие слоты где стоят — выведено по странице билда и окну игры; статы отдельных украшений неизвестны (в игре видна только сумма).
- **Доски Даэваниона в файле оверлея обновляются не сразу** после перестановки узлов (уровни умений — сразу). Приложение предупреждает, если уровни не сходятся с досками. Перезаход персонажем не помогает; новые доски приходят сами, у владельца — примерно через 12 часов (см. data-sources.md). Похоже, так же ведёт себя **Знание о видах** после перекрутки статов.
- **Специализации.** Оверлей отдаёт у всех активных умений «1, 2» (у стигм «1, 2, 3, 4») — это похоже на число открытых слотов, а не на выбранные варианты. Приложение распознаёт этот случай, не считает специализации известными и предлагает отметить их вручную на странице «Умения».
- **Какие статы выпадают на каком слоте и в какой ячейке рода.** Полной таблицы нет; используем наблюдения (данные игрока + скриншоты приложения друга) и дополняем их тем, что видно у персонажей. См. `gamedata/gearOptions.ts`, `gamedata/genus.ts`.
- **Приоритеты статов** во встроенном гайде — оценка помощника (в самом гайде их нет), помечено в интерфейсе.
- **Веса статов в гайдах Questlog** — производная: как часто авторы берут стат на вещах и в камнях (60% — автор, 40% — пять авторов класса); приоритеты Знания о видах — оценка помощника. Сами авторы весов не задают.
- **(до 0.16) Гайды других классов** (не стража) собирались по гайдам и данным топа, на персонажах владельца не проверены. Общее для них: специализации известны только из гайдов (подсчёта по билдам нет); раскладка доски Ариэль взята как у стража и тайминги «одной кнопки» — как у стража (обе помечены «оценка помощника»); спорные места — в разделе «Что под вопросом» каждого разбора в `research/`. Один источник (aion2-meta.com) пишет, что NCSOFT запрещает макросы мыши, — «одна кнопка» остаётся на усмотрение игрока.
- **Связка (макрос игры).** Известно по гайдам и скриншотам игры: окно «Умения» → «Связки», до 3 наборов; шаг — ячейка панели (до 4 умений, нижний ряд 0 главный); задержка от 10 мс; работает, пока клавиша зажата, по кругу, пропуская умения на откате; ручной ввод перебивает связку. **Не известно:** начинает ли связка с первого шага после отпускания клавиши и как часто короткие клики теряются с резервом умений (20 мс / 35 мс — значения корейских стражей, не наши замеры). Название настройки «резерв умений» (Skill Queue) в русском клиенте не сверено.
- **Ранги Бездны**: известно только, что номер 18 = «Воин 9-го ранга» (как пишет оверлей); остальные названия — по аналогии.
