## Что важно помнить (быстрый контекст)

- Владелец — игрок AION 2 (глобальная версия, Steam), основной персонаж — **страж**, PvE. Цель по умолчанию — **сводный гайд** (decisions/0005): 8 гайдов для глобальной версии + статистика топ-стражей с metabot.gg. Mobalytics — второй встроенный.
- Данные персонажа — **только из локального файла оверлея Questlog**. Закрытый API Questlog не используем (это их внутренний API, не для сторонних программ).
- Справочники собраны скриптом `npm run gamedata` с публичных страниц metabot.gg (умения, специализации, доски, пулы аркан) и из локального `game-data-v2.json` Questlog (статы). Специализации и доски скачаны **только для стража** — для другого класса запустите `npm run gamedata -- --classes <класс>`.
- Названий и иконок предметов в данных оверлея нет. Известные вещи (надетые у владельца) — в `gamedata/art.json` с официальными названиями и артом (decisions/0004); остальные называются по слоту, пользователь может дать своё имя. Арканы называются точно (их ID расшифровываются).

## Что под вопросом

- **Названия.** Русский клиент сверен по видео окна умений, окнам игры и странице билда Questlog на русском; четыре названия умений стража и редкие статы пока — перевод приложения (см. data-sources.md). Не сверено: русские названия грейдов, вариант аркан «жизни» («Зеркало жизни»), пятый род «Особый».
- **Пантеон**: какие слоты где стоят — выведено по странице билда и окну игры; статы отдельных украшений неизвестны (в игре видна только сумма).
- **Доски Даэваниона в файле оверлея обновляются не сразу** после перестановки узлов (уровни умений — сразу). Приложение предупреждает, если уровни не сходятся с досками. Перезаход персонажем не помогает; когда оверлей обновляет доски — неизвестно (см. data-sources.md).
- **Специализации.** Оверлей отдаёт у всех активных умений «1, 2» (у стигм «1, 2, 3, 4») — это похоже на число открытых слотов, а не на выбранные варианты. Приложение распознаёт этот случай, не считает специализации известными и предлагает отметить их вручную на странице «Умения».
- **Какие статы выпадают на каком слоте и в какой ячейке рода.** Полной таблицы нет; используем наблюдения (данные игрока + скриншоты приложения друга) и дополняем их тем, что видно у персонажей. См. `gamedata/gearOptions.ts`, `gamedata/genus.ts`.
- **Приоритеты статов** во встроенном гайде — оценка помощника (в самом гайде их нет), помечено в интерфейсе.
- **Ранги Бездны**: известно только, что номер 18 = «Воин 9-го ранга» (как пишет оверлей); остальные названия — по аналогии.
