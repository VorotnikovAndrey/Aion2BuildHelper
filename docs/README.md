## Что важно помнить (быстрый контекст)

- Владелец — игрок AION 2 (глобальная версия, Steam), основной персонаж — **страж**, PvE. Следует гайду Mobalytics «Aion 2 Templar PvE Build» (он встроен).
- Данные персонажа — **только из локального файла оверлея Questlog**. Закрытый API Questlog не используем (это их внутренний API, не для сторонних программ).
- Справочники собраны скриптом `npm run gamedata` с публичных страниц metabot.gg (умения, специализации, доски, пулы аркан) и из локального `game-data-v2.json` Questlog (статы). Специализации и доски скачаны **только для стража** — для другого класса запустите `npm run gamedata -- --classes <класс>`.
- Названий предметов в доступных данных нет: вещь называется по слоту, пользователь может дать своё имя. Арканы называются точно (их ID расшифровываются).

## Что под вопросом

- **Специализации.** Оверлей отдаёт у всех активных умений «1, 2» (у стигм «1, 2, 3, 4») — это похоже на число открытых слотов, а не на выбранные варианты. Приложение распознаёт этот случай, не считает специализации известными и предлагает отметить их вручную на странице «Умения».
- **Какие статы выпадают на каком слоте и в какой ячейке рода.** Полной таблицы нет; используем наблюдения (данные игрока + скриншоты приложения друга) и дополняем их тем, что видно у персонажей. См. `gamedata/gearOptions.ts`, `gamedata/genus.ts`.
- **Приоритеты статов** во встроенном гайде — оценка помощника (в самом гайде их нет), помечено в интерфейсе.
- **Ранги Бездны**: известно только, что номер 18 = «Воин 9-го ранга» (как пишет оверлей); остальные названия — по аналогии.
