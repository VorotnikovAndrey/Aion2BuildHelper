## Дальше

- **Названия предметов и питомцев.** Сейчас вещи называются по слоту (можно дать своё имя). Идея: подтягивать названия с публичных страниц базы для ID, которые видит приложение, и кэшировать.
- **Справочники для всех классов** (`npm run gamedata -- --classes all`) — когда понадобится второй персонаж (у владельца есть чародей и волшебник).
- **Таблица опций шмота и рода по слотам** из клиента вместо наблюдений — точнее «что ловить» и максимумы.
- **Сравнение двух гайдов** на одном персонаже («что изменится, если перейти на эндгейм-гайд»).
- **Пулы аркан с учётом сета**: подсказка «собирать магию или жизнь» по весам гайда.
- **Ресурсы из оверлея** (`currencies.json`): кристаллы Даэваниона против стоимости плана досок.
- **Уведомления**: «оверлей обновил персонажа — вот что изменилось».
- **Установщик** (electron-builder), если понадобится ставить без исходников.
