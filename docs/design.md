# Дизайн

Тёмная тема в духе интерфейса Aion: глубокий сине-чёрный фон, **золотой** акцент (рамки, активное, главное), голубой **«эфир»** для второстепенного (что ловить, цели на досках). Плотная, но спокойная подача: цифра → вывод → действие.

## Токены (`src/renderer/src/styles.css`, блок `@theme`)

| Токен | Для чего |
|---|---|
| `bg`, `sidebar`, `surface`, `surface-2`, `surface-3` | фон окна → меню → карточки → наведение → поповеры |
| `line`, `line-strong` | рамки |
| `ink`, `ink-2`, `ink-3` | текст: основной / вторичный / приглушённый |
| `accent`, `accent-2`, `accent-soft`, `on-accent` | золото: главные кнопки, активное меню, главные умения |
| `aether`, `aether-soft` | «что ловить», нужные узлы досок |
| `good`, `teal`, `warning`, `critical`, `info` (+ `-soft`) | статусы и вердикты — **только с подписью или иконкой** |
| `grade-mythic/unique/epic/rare/common` | грейды предметов и ячеек рода, как в игре |
| `card-magic-*`, `card-vigor-*` | фон карт аркан |
| `series-*`, `grid`, `axis` | графики |

Hex-коды в компонентах не пишем. Шрифт — Inter Variable (встроен).

## Темы и масштаб

Значения выше — тема по умолчанию «Золото Элиоса». Пользователь выбирает тему в «Настройки → Оформление»: `src/shared/theme.ts` (основы `THEME_BASES`, готовые темы `THEME_PRESETS`, палитра акцентов) → `src/renderer/src/lib/theme.ts` переписывает на лету `bg`, `sidebar`, `surface*`, `accent` и `on-accent`. Поэтому:

- текст на акцентном фоне — только `text-on-accent` (тёмный или белый по яркости акцента);
- оттенки акцента — `accent-2`, `accent-soft`, `glow-accent` или прозрачность (`bg-accent/20`) — они пересчитываются сами;
- статусы, грейды, «эфир», фон карт аркан и графики от темы не зависят;
- единственное место с hex тем — `shared/theme.ts` (и мини-превью тем в настройках, которые рисуют именно цвета темы).

Масштаб 80–200% — `setZoomFactor` в main-процессе (`src/main/zoom.ts`: Ctrl+колесо, Ctrl +/−/0), в браузерном режиме — CSS `zoom`. Подсказка — `components/ZoomToast.tsx`. Вёрстка должна выдерживать 200%: сетки перестраиваются по ширине, а не ломаются.

## Язык цвета (везде одинаковый)

| Цвет | Значит |
|---|---|
| зелёный | как в гайде |
| жёлтый | приемлемо, почти, или нужно проверить (например, специализации, которых оверлей не видит) |
| красный | не по гайду: не хватает, стоит не то, бесполезно |
| серый | гайд об этом молчит |

Вердикт и его причина считаются в `src/renderer/src/lib/status.ts` (`skillTone`, `levelTone`, `specTone`, `verdictTone`, `shareTone`). **Причина всегда показывается в подсказке** — цвет без объяснения не используем.

## Подсказки

Почти у каждого элемента — подсказка при наведении (`Tooltip` из `components/ui/InfoTip.tsx`, у `Pill` — проп `tip`, у `StatTile` — `hint`). Подсказка рисуется порталом поверх окна, поэтому не обрезается карточками и списками, и сама выбирает сторону. Пишем в ней: что это, почему такой цвет, что сделать.

## Значки статуса

`components/StatusBadge.tsx` — нарисован в Figma (файл «Aion2 Build Helper — значки статуса», компонент `StatusBadge`, сетка 16 px) и перенесён как SVG. Форма + цвет + знак: круг с галочкой — `ok`, ромб с «!» — `warn`, восьмиугольник с крестиком — `bad`, скруглённый квадрат с «i» — `info`. Цвета — токены `--color-good` / `--color-warning` / `--color-critical` / `--color-info` (градиент: +35% белого сверху, ×0,78 снизу; обводка ×0,28). Для статусов — только он, не lucide. См. decisions/0006.

## Иконки

`components/icons.tsx`: `SkillIcon` (иконка умения по ID, с цветной обводкой по вердикту и приглушением, если не изучено) и `SpecIcon` (щиты специализаций 1–5 и золотой значок стигм). Файлы — `src/renderer/public/icons`, скачиваются `npm run gamedata`; если иконки нет — показывается буква.

## Арт игры

`components/art.tsx`:
- `ItemIcon` — вещь как в инвентаре: подложка грейда (`frameArt`), арт, заточка «+N» белым с обводкой (`.game-num`), значок итога в углу (`StatusBadge`). Нет арта — значок слота. По иконкам мифических, эпических, уникальных и легендарных вещей пробегает блеск (`.fx-shine`).
- `GameSlot` — та же ячейка для любого арта (камни — `StoneIcon`).
- `ArcanaCardArt` — карта арканы: арт, золотая рамка, плашка заточки (`.game-enchant`); свечение `card-glow-magic` / `card-glow-vigor`.
- `TitleEmblem` — эмблема категории титула со свечением цвета грейда; `PantheonPiece` — украшение в рамке своего вида.
- `ClassIcon` (game.tsx) — эмблема класса из игры.

Стили ячеек — в `styles.css` (`.game-slot`, `.game-num`, `.game-enchant`): это единственное место, где у арта есть тени. Цвета грейдов — токены `--color-grade-*` (как цвета названий в игре).

## Вердикты строк (шмот, род, манакамни)

| Вид | Значит |
|---|---|
| зелёный | нужно по гайду (вес 4–5) |
| жёлтый | приемлемо (3) |
| жёлтый пунктир | слабо (1–2), при случае заменить |
| красный зачёркнутый | не по гайду — менять |
| голубой | что ловить |

## Компоненты

`components/ui`: `Card` (заголовок, `hint` «?», действия), `Button` (`primary` — одна на экран), `Pill` (+ `toneOfShare`, `toneOfScore`), `ProgressBar`, `ScoreRing`, `InfoTip`/`Tooltip`, `PageHeader`, `StatTile`, `Tabs`, `Segmented`, `Modal`, `EmptyState`, `Legend`, `Pager` (страницы длинного списка: «показано X–Y из N», номера, размер 10/25/50/100; срез — `shared/paging.ts`).

`components/game.tsx`: `Name` (русское + английское мелко), `VerdictChip`, `WishChip`, `GradeText`, `ImpactPill`, `ClassIcon`, `WeightDots`. `components/GuideSwitcher.tsx` — выбор гайда в шапке страниц билда.

## Правила

1. Каждый блок объясняет себя (`hint`, подзаголовок страницы, легенда под таблицей).
2. Не показываем число без вывода, если вывод можно дать (шанс → «1 из 7 315», уровень → «не хватает 2, откроется спец. 5»).
3. Пустое состояние — тоже экран: что здесь будет и что сделать.
4. Анимации короткие (0,35 с появление, до 1 с счётчики). Уровень — «Оформление → Анимации» (`full` / `calm` / `off`, атрибут `data-motion` на `<html>`, хуки `useAnimate` / `useFancy` в `lib/motion.ts`). Декоративное, что движется само (эфир на фоне, блеск вещей, искры), — только при `full`: классы `fx-ambient`, `fx-shine` или `useFancy()`. `?static` выключает всё, системное «уменьшить движение» понижает `full` до `calm`. Эффекты — `components/fx.tsx` (`AetherBackdrop`, `Sparks`, `CountUp`) и блок «Анимации» в `styles.css`.
5. Честно о данных: догадки помечены, сомнительные данные — с предупреждением и способом поправить.
