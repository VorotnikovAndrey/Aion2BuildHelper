# Архитектура

```
 Questlog overlay ──writes──▶ %APPDATA%\Questlog\aion-2\characters.json
                                         │ fs.watch + опрос раз в 15 с
                                         ▼
 ┌──────────────── main (Electron) ────────────────┐
 │ questlog.ts  читать → parseQuestlogCharacters   │
 │              → история: diff со снимком → JSON  │
 │ storage.ts   настройки, свои гайды, история     │──IPC──▶ preload (window.api)
 │ ipc.ts       контракт shared/api.ts             │
 └─────────────────────────────────────────────────┘
                                                              │
 ┌──────────────── renderer (React) ───────────────────────────▼─┐
 │ lib/store.ts   zustand: источник, настройки, гайды            │
 │ lib/report.ts  персонаж + гайд + отметки → analyzeBuild()     │
 │ pages/*        только показывают BuildReport                  │
 └───────────────────────────────────────────────────────────────┘
                     ▲
       src/shared: types, questlog/parse, gamedata/*, guide/*, analysis/*, names
```

## Слои

**`src/shared` — вся логика.** Без Electron и React, поэтому тестируется vitest'ом и одинаково работает в приложении и в браузерном режиме.

- `questlog/parse.ts` — терпимый разбор файла оверлея в модель `Character` (`types.ts`). Кривые записи пропускаются, неизвестные поля игнорируются.
- `gamedata/*` — справочники. Сгенерированные JSON (`generated/`) + ручные русские названия и знания о механиках (слоты, арканы, род, опции шмота, титулы). `art.json` + `art.ts` — арт игры по ID (иконки вещей, рамки грейдов, камни, карты аркан, эмблемы, пантеон); сами файлы — в `src/renderer/public/art`, интерфейс рисует их через `components/art.tsx`.
- `guide/*` — формат гайда (`types.ts`), проверка импорта (`normalizeGuide`), встроенные гайды (`builtin/`; их свои тексты — ключами перевода, собирает `localize.ts`).
- `analysis/*` — разбор персонажа по гайду. Каждый раздел — свой модуль с функцией `analyzeX(char, guide)` и оценкой 0–100. `titles.ts` — надетые титулы, бонусы коллекции и титул полезнее надетого. `rotation.ts` — раздел гайда `combat` рядом с персонажем: какая ячейка связки подходит по уровню умения, чего не хватает, подсказки по статам. `inputMacro.ts` — расчёт макроса ПО мыши («одна кнопка»): длина прогона, удержания, паузы, предупреждения. `progress.ts` — события прогресса между двумя разборами (для празднований и уведомлений). `top.ts` — сравнение с топ-игроками класса. `build.ts` собирает всё в `BuildReport` и строит список «что сделать дальше». `history.ts` — сводка снимка и разница между снимками.
- `theme.ts` — темы оформления и шаги масштаба (`normalizeUi` чинит сохранённые настройки).
- `names.ts` — `Namer`: как назвать умение / стат / вещь / узел официальным названием (русским или английским — режим в настройках «Язык») с учётом своих названий пользователя; `term()` — то же для справочников `{ ru, en }` (классы, слоты, грейды, доски).
- `i18n/` — перевод интерфейса: `t('русский текст {подстановка}')`, `tn(n, 'формы|числительного')`, список языков `LOCALES`, словари `locales/<язык>.json`. Язык окна — из адреса (`?lang=`), смена языка перезагружает окно (decisions/0010).

**`src/main` — Electron.**

- `questlog.ts` — путь к файлу (стандартный или выбранный), чтение, слежение (`fs.watch` на папку + страховочный опрос), запись истории при каждом обновлении.
- `storage.ts` — `%APPDATA%\Aion2 Build Helper`: `settings.json`, `guides/*.json`, `history/<персонаж>.json`, `snapshots/<персонаж>.json`. Запись атомарная (через `.tmp`).
- `ipc.ts` — обработчики `window.api` (контракт — `shared/api.ts`): источник, настройки, гайды (+ диалоги импорта/экспорта), история, служебное.
- `updater.ts` — обновления приложения (electron-updater, выпуски GitHub): проверка, скачивание в фоне, установка при перезапуске; состояние — `shared/updates.ts`.
- `gamedataCheck.ts` — проверка справочников после патча: свежие страницы metabot.gg → те же разборщики (`scripts/gamedata/parsers.mjs`) → сравнение (`shared/gamedata/diff.ts`).
- `zoom.ts` — масштаб окна (Ctrl+колесо, Ctrl +/−/0) и применение оформления к окнам.
- `devShots.ts` — режим автоскриншотов (`npm run shots`).

**`src/renderer` — интерфейс.**

- `lib/store.ts` — состояние: данные источника, настройки, свои гайды; хуки `useCharacter`, `useActiveGuide`, `useCharacterPrefs`.
- `lib/report.ts` — `useCharacterContext()`: персонаж + гайд + ручные отметки → мемоизированный `BuildReport`.
- `lib/webApi.ts` — реализация `window.api` для браузера (`npm run dev:web`): данные отдаёт dev-сервер Vite, настройки — localStorage.
- `pages/*` — экраны; `components/ui/*` — общие элементы; `components/game.tsx` — игровые (вердикты, грейды, классы).

## Данные пользователя

| Что | Где | Зачем |
|---|---|---|
| Настройки | `settings.json` | путь к файлу оверлея, оформление (тема, масштаб), режим названий, свои названия, скрытые персонажи, по персонажу: гайд, ручные специализации, чек-лист, задачи, заметки |
| Свои гайды | `guides/<id>.json` | формат `shared/guide/types.ts` |
| История | `history/<сервер_имя>.json` | до 3000 записей: сводка снимка + список изменений |
| Последний снимок | `snapshots/<сервер_имя>.json` | с ним сравнивается следующее обновление |
