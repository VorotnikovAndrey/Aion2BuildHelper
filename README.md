# 🛡️ Aion2 Build Helper

**Десктоп-помощник по билду персонажа в AION 2.** Берёт вашего персонажа из оверлея Questlog, сравнивает с выбранным гайдом и показывает, чего не хватает: какие специализации поставить, какие строки на шмоте менять, что ловить на арканах и в Знании о видах, какие узлы Даэваниона брать следующими.

> Статус: **версия 0.5** ([что нового](CHANGELOG.md)). Личный инструмент под одного игрока (страж), но ничего не зашито под конкретного персонажа или гайд: поддерживаются все персонажи из оверлея и любые гайды.

## Что умеет

| Раздел | Что показывает |
|---|---|
| **Обзор** | Боевая мощь, ранг Бездны, оценка готовности билда 0–100 по разделам и список «что сделать дальше» — от самого важного. |
| **Везде** | Арт из игры (вещи с рамками грейдов, карты аркан, эмблемы титулов и классов, пантеон, иконки умений), официальные русские названия, значки статуса (зелёный круг — как в гайде, жёлтый ромб — обратить внимание, красный восьмиугольник — не по гайду) и подсказка при наведении почти на каждом элементе. |
| **Умения** | Уровень против цели гайда и откуда он складывается (очки, доски, арканы, шмот). Какие специализации нужны сейчас и какие откроются позже. Стигмы и пассивки. |
| **Ротация** | Как играть по гайду: связка (макрос игры) по шагам и ячейки панели столбиком, как в игре; что жать вручную, начало боя, раскладка клавиш. «Одна кнопка» — макрос для ПО мыши с расчётом нажатий. Советы под персонажа: чего не хватает для ротации, какая ячейка подходит по уровню умения, как жать умение при ваших статах. |
| **Шмот** | Панель снаряжения как в окне персонажа. Каждая строка вещи: нужно / полезно / слабо / менять. Камни маны. Что ловить на этом слоте (только то, что на нём встречается). Свои названия вещей. |
| **Арканы** | 5 карт: нужные умения, шансы заточки дотянуть главное умение до ур. 3–4, шанс новой карты с нужным набором, сеты, что искать первым. |
| **Даэванион** | Все 6 досок с отмеченными узлами, цели гайда, самый дешёвый путь к нужным узлам и план прокачки по очкам. Сумма статов с досок. |
| **Знание о видах** | 5 родов по ячейкам: что уже как надо, что перебросить и что ловить (с максимумами). |
| **Питомцы и коллекции** | Титулы (надетые, бонусы коллекции, что надеть полезнее), пантеон, питомцы, крылья, облики, монолиты, персонажи аккаунта. |
| **Статы** | Панель «Показатели персонажа» как в игре и полный лист характеристик с важностью по гайду и вкладом досок. |
| **Сравнение с топом** | Вы против тысяч топ-игроков класса: боевая мощь на распределении, умения, стигмы, заточка, арканы, доски — и где отставание больше всего. |
| **История** | Снимок при каждом обновлении оверлея: график боевой мощи и лента изменений по страницам (заточки, вещи, уровни, узлы, питомцы). |
| **Гайды** | Сводный гайд стража (8 гайдов + данные топ-игроков) и Mobalytics, свои гайды, редактор, импорт/экспорт JSON. Разные гайды на разные этапы — переключаются в один клик. |
| **Чек-лист** | Вехи гайда отмечаются сами по данным; разовые дела и свои задачи — вручную; заметки. |
| **Настройки** | Источник данных, названия, уведомления о прогрессе (всплывашки с искрами и уведомления Windows), проверка справочников после патча. |
| **Оформление** | 10 готовых тем и свои цвета (основа + акцент), масштаб 80–200% (Ctrl+колесо, Ctrl +/−/0), анимации: полные, спокойные или выключены. |

## Откуда данные

- **Персонаж** — файл оверлея [Questlog](https://questlog.gg/aion-2) `%APPDATA%\Questlog\aion-2\characters.json`. Оверлей сам обновляет его, пока игра запущена (обычно при смене зоны); приложение следит за файлом и подхватывает изменения. В игру приложение не лезет и ничего никуда не отправляет.
- **Справочники** (умения всех классов, специализации, доски Даэваниона, пулы аркан, титулы, статы) — из клиента глобальной версии через [metabot.gg](https://metabot.gg/en/aion-2) и файлы Questlog. **Арт** (иконки вещей, карты аркан, пантеон) — с публичного CDN картинок Questlog по списку `src/shared/gamedata/art.json`. Лежат внутри приложения, интернет не нужен. Подробно — [docs/data-sources.md](docs/data-sources.md).

## Быстрый старт

Нужен [Node.js](https://nodejs.org/) 22+.

**Проще всего:** ярлык **Aion2 Build Helper** на рабочем столе (создаётся командой `npm run shortcut`). Приложение открывается без окна консоли и каждый раз собирается из свежего кода.

Для разработки — `start.cmd` (горячая перезагрузка; сам поставит зависимости при первом запуске) или:

```bash
npm install
```

```bash
npm run dev
```

Остальные команды — в [docs/development.md](docs/development.md).

## Гайды

Гайд — это цель: нужные умения и специализации, веса статов, приоритеты аркан, узлы досок, титулы, ротация и советы. По умолчанию цель — **сводный гайд стража**: в чём сходятся 8 гайдов для глобальной версии и что реально носят 3 741 топ-страж ([разбор](docs/research/templar-pve-2026-11.md)). Формат не привязан к сайту — всё задаётся игровыми ID, поэтому любой гайд (Mobalytics, видео, свой) переносится одинаково:

1. **Скопировать встроенный и поправить** — «Гайды → Скопировать и править».
2. **Собрать в редакторе** с нуля.
3. **Импортировать JSON** — например, попросить AI-агента перевести новую статью в формат гайда по [docs/guides.md](docs/guides.md).
